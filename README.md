# Project 1: Rule-Based Chatbot (DecodeLabs Internship)

## What is this?
This is a simple rule-based chatbot that responds to user inputs using a predefined dictionary. It is my first project during the AI Internship at DecodeLabs.

## How to Run
1. Install Python 3 on your computer
2. Run the file: chatbot-rulebase.py
3. Type commands like: hello, hi, bye, name, age, help, thank
4. Type "exit" to stop the chatbot

## Commands and Replies
 Command : Reply
 hello :hi there!, how i can help u? 
 hi : hey, welcome to decodelabs 
 bye : good bye, have nice day! 
 name : i am decodebot, Your rule based assistant! 
 age : i was just created, so i am just 0 day old 
 help : i am here for ur help 
 thank : you r welcome! 
anything else : I don't understand that yet
